# 🛍️ SmartShop

SmartShop is a beginner-friendly mini e-commerce website built using HTML, CSS and JavaScript.

## 📌 About the Project

SmartShop is a simple online shopping website where users can view products, search products, filter products and add products to a shopping cart.

## ✨ Features

- Product listing
- Product search
- Price filtering
- Add to Cart
- Remove from Cart
- Cart total
- Local Storage
- Dark Mode
- Responsive Design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
